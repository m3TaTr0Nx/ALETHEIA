# Aletheia Late-Alpha Architecture

## Source container

A corpus is immutable text plus a metadata envelope. Analysis can select chapters or highlights but never writes back into source.

## Temporal/historical envelope

Aletheia separates:
- written/composition range,
- proposed original/core range,
- event-time range,
- named historical period,
- region/setting,
- source-referenced celestial or cosmological period.

Ranges are permitted; precision improves only when evidence supports it.

## Six interpretation fabrics

1. Literal/source-world.
2. Metaphorical/symbolic.
3. Philosophical/logical.
4. Historical worldview.
5. Scientific/technical.
6. Speculative substitution.

Every fabric has an independent mutation state and counter. Mutation in one fabric never silently permutes another.

## Terminology sweep

Exact surface token -> normalized lexeme -> occurrences -> capitalization flags -> finite-field carrier -> optional concept candidates.

Carrier equality is not semantic equality. Lexical equality is not ontological identity.

## Graph/hypergraph substrate

Pair edges capture local binary relations. Hyperedges preserve higher-order structures such as sentence-level concept bundles, proposition structures, or cross-span analogies.

## Distance chassis

Aletheia reports components instead of laundering them into one unexplained scalar:
- temporal interval distance,
- hierarchy ultrametric,
- finite-field valuation-like distance,
- lexical Hamming distance,
- signed relation-orientation pseudoscalar.

The pseudoscalar and composite are experimental Aletheia constructs, not standard canonical metrics.

## Oracle

The in-app Oracle validates a public network target, fetches into a sandbox, hashes bytes, records provenance, extracts inert text where supported, and only then permits corpus creation.

## Wolfram

Wolfram can supply exact canonical hypergraph forms, isomorphism/automorphism analysis, embeddings, hypermatrices, finite fields GF(p^n), and multiway state/causal/branchial graphs. These remain computational objects, not interpretive authority.

## Multiview Glass

Anchors route through independently permissioned channels. Visibility does not grant write access; write access does not grant merge authority; merge authority never grants source mutation.

## Future DiazAI bridge

The late-alpha keeps DiazAI, GrandState, Ultracode, and mint transitions locked behind provenance closure, merge-integrity confirmation, and explicit authorization.
