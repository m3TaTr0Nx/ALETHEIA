# Structural Triptych Demo Method

The production demo compares three source-derived normalized graphs:

1. Genesis 3:1-19
2. 1 Enoch 6-10
3. Aeschylus, *Prometheus Bound* (fire/arts and punishment sequence)

The demo does not claim these sources are identical, historically dependent, or mutually explanatory.

Each source is normalized into role nodes such as:

- authority
- boundary/norm
- agent
- recipient
- capability
- transfer event
- recipient transformation
- consequence

1 Enoch contains an additional coordination node. Prometheus contains an additional acquisition relation. Genesis includes consequence relations to both agent and recipient.

The pairwise score is therefore not hard-coded to equality. It is calculated from graph-role, relation, degree, proposition, and edge-class components.

Expected production-candidate pairwise scores are all above 0.75. Exact values are generated by the engine at runtime and are asserted in tests.

The demo exposes the exact components so researchers can disagree with the weighting or replace the metric.
