# Research Capsules

This directory stores non-executable research material.

Use capsules for philosophical, theological, metaphorical, speculative, mathematical, narrative, or discarded architectural ideas that may be useful later but are not part of the supported application.

A capsule must state:

- origin;
- date;
- status;
- whether it is descriptive, speculative, metaphorical, or experimental;
- any source material it depends on;
- whether it has been implemented.

Capsules must not be imported into runtime code automatically.

The purpose of this directory is to preserve potentially useful ideas without allowing them to mutate the healthy corpus application.
